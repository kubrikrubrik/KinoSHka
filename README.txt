КИНОВДВОЁМ — установка на GitHub Pages

ФАЙЛЫ
- index.html — всё приложение в одном файле. Никаких папок создавать не нужно.

КАК ОПУБЛИКОВАТЬ
1. Откройте свой репозиторий на GitHub.
2. Нажмите Add file → Upload files.
3. Перетащите index.html (можно также README.txt) прямо в корень репозитория.
4. Нажмите Commit changes.
5. Откройте Settings → Pages.
6. В разделе Build and deployment выберите Deploy from a branch.
7. Branch: main, папка: /(root), затем Save.
8. Через минуту сайт будет доступен по адресу https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/

КАТАЛОГ ФИЛЬМОВ
Встроенная подборка содержит фильмы разных жанров. Чтобы искать по большой международной базе TMDB:
1. Создайте бесплатный аккаунт на themoviedb.org.
2. Откройте Settings → API и запросите API key (v3) или Read Access Token (v4).
3. В приложении откройте Настройки, вставьте ключ и сохраните.
4. Введите название в поле «Поиск в каталоге TMDB» и добавляйте найденные фильмы кнопкой +.

ДАННЫЕ И ПЕРЕНОС
Оценки, статусы и добавленные фильмы хранятся локально в браузере на устройстве, где вы ими пользуетесь. В Настройках есть экспорт и импорт JSON.
Важно: GitHub Pages публикует сам сайт, но не синхронизирует localStorage между телефонами. Для общего использования с двух устройств потребуется отдельное облачное хранилище/база данных. Не очищайте данные браузера без резервной копии.
